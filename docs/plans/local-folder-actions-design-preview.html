RECOMMENDATION

建议先选 B：信息行编辑胶囊

两种方向都让封面保持完整。B 把操作放在次要信息旁，名称仍可占满一行；文字“编辑”也比孤立的三点更好认。A 适合想要更克制的图标入口。

NEXT DECISION

需要用户选择的细节

  • 将来统一其他 UI 时，可复用 36–40px 目标、7px 菜单间距、右边缘锚点和可见焦点。
