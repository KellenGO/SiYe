四野 v1.2.0 带来研究空间、站内阅读和可选 AI 助手，方便把跨平台搜索资料集中整理成自己的笔记。

## 下载与升级

- **推荐 Windows 10/11 64 位用户下载 `SiYe-Setup-Windows-x64.exe`**，按当前用户安装，无需管理员权限。已安装的用户先退出四野，再运行安装器覆盖升级。
- 需要免安装运行时下载 `SiYe-Windows-x64.zip`，完整解压后双击 `四野.exe`，不要只取单个 EXE。
- 两种方式都无需另装 Python 或 Node，默认在浏览器打开 `http://127.0.0.1:8080`；需本机已有 Chrome 或 Edge。
- 同名 `.sha256` 文件用于核验下载内容。收藏、空间和笔记保存在本机；升级前建议备份 `%LOCALAPPDATA%\SiYe\data`，另行保留原程序目录中的 `browser_data` 登录资料。AI 会话文件不包含在单独的收藏导出中。

## 本版变化

- **研究空间与富文本笔记**：将搜索和收藏中的资料集中到主题空间，支持切换、归档和继续研究；笔记自动保存，支持格式编辑、撤销重做及 Markdown 导出，原收藏保持独立。
- **站内阅读、视频与评论**：在统一抽屉或全屏查看小红书、抖音、B站及知乎支持的内容，调整字号、播放可用视频和按需展开评论；固定阅读工具栏、评论回复层级和互动数据图表让浏览更方便。
- **可选官方 AI 扩展**：在「设置 → 扩展管理」下载官方 [SiYe-AI](https://github.com/KellenGO/SiYe-AI/releases/tag/v0.1.0)，首次安装默认关闭。扩展支持安装、开关、详情及卸载确认，基础程序不再捆绑模型 SDK 和 Claude 运行程序。
- **围绕资料研究**：开启 AI 扩展并配置支持工具调用的模型服务后，可按正文、评论和字幕读取资料、追问并查看来源；回答由用户确认后追加到笔记。联网补充默认关闭，可选本地视频转写组件需另装，模型按需下载。
- **笔记与 AI 并排**：桌面支持左右并排、拖动分隔线和宽度记忆；窄屏提供独立编辑界面。聊天历史保存于本机，重启后可继续查看。
- **更及时的搜索结果**：结果到达即展示，支持单平台渐进重搜，复用成功的搜索会话，减少重复启动浏览器和等待；实际速度仍取决于平台与网络。
- 修复搜索 worker 停止失败时的账号槽位释放、笔记保存重试与重复追加、GitHub 匿名接口限流时的扩展下载回退，并改进详情操作、键盘焦点和窄屏布局。

## 使用边界

- 平台登录、验证、权限和风控仍可能导致搜索或阅读失败。知乎部分真实会话仍返回 403，不能保证所有回答和文章均可读；受限时请使用原文入口。评论及回复是有限样本。
- AI 功能需要自行配置模型服务；问题和相关资料会发送给该服务，连接测试和研究可能产生费用。引用与读取记录供核对，不能保证模型结论正确；卸载扩展默认保留 AI 配置和聊天，选择清除才删除对应数据。
- 可选转写不随基础包安装。干净 Windows 的 ASR 组件／DLL 兼容性、无字幕中文 B站自动转写及真实模型服务组合尚未完成完整人工验收；失败会保留已有文字并提示缺口。
- 320px 极窄屏的收藏夹信息菜单仍有已知越界边界；已有丢失的 AI 历史无法通过升级恢复。
