## 尚未完成的真人验收与已知边界

- 真实模型服务、费用和不同服务商的工具调用兼容性尚无本次逐项真人记录；模拟服务通过不能代表所有服务可用。
- 干净 Windows 的可选 ASR／DLL 兼容性、无字幕中文 B站自动转写组合仍需实际使用者验收。
- 首次安装、覆盖升级后的四平台登录／搜索、收藏／空间／笔记保留及托盘操作尚无本次完整真人记录；自动化安装／运行／卸载仅验证其覆盖的场景。
- 知乎部分真实会话仍返回 403，不能宣称已恢复。320px 收藏夹信息菜单仍有存量越界边界。
- 本机此前丢失的 AI 配置与历史未恢复，升级不能找回；不得以临时数据验收通过替代恢复证据。
- 独立 AI 仓库现有 Axios／Vite 两项 high audit 待依赖维护者处理；基础程序本次未修改这些依赖。

以上限制已在面向用户的发布说明中列出相关使用边界，发布不等于上述真人验收已完成。

## 发布核对

1. 提交发布说明与日期，核对 Git 状态、远端 HEAD 和版本；打 `v1.2.0` tag。
2. 推送 master 与 tag，工作流从该提交重新构建、完整回归、解包及安装验收，通过后创建正式 Release。
3. 核对正式安装器、ZIP 及两份 SHA256、匿名下载、正式 tag／提交与发布说明。
4. 更新发布状态及正式摘要，清理本次临时大文件，核对个人资料未发生验收引起的改变，释放协作登记。
