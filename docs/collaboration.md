## 留记录的边界

- 功能当前行为与边界写对应 `docs/features/`，长期取舍写 `docs/decisions/`，用户可感知版本变化写 `CHANGELOG.md`。这里不复制改动清单、测试输出、界面文案或完整调试过程。
- 需要交接时，短记「任务 ID / 提交或分支、当前状态、关键发现、验证及未验证、下一步与归属」。仅涉及运行效果时说明源码、构建产物与正在运行的版本是否一致。
- 支线 worktree 的本文件是独立副本。以 `git worktree list` 确认主工作区路径；主工作区有写入负责人时由其串行更新公共记录，支线先在自身提交中保留任务 ID，集成者再汇总尚未解决的事项。无法确认公共记录时先做只读检查。
- 旧的完整交接仍可从 Git 查看：`git show 01b4453:docs/collaboration.md`；按任务 ID 搜提交可用 `git log --all --grep=<任务ID>`。不为普通已完成任务另建归档或重复写交接。
