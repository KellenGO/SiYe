# 决策：共享内容双视图与独立于收藏的详情

- 日期：2026-09-27
- 状态：采用并实施
- 相关：[搜索体验](../features/search-experience.md)、[本地收藏](../features/favorites-library.md)

## 背景

内容结果页需要同时支持原列表与已认可的封面网格；文件夹根页导航继续使用图标卡片，不恢复左侧导航栏。搜索、历史与跨平台归档并不一定存在个人收藏记录。

## 选项

- 各页面单独实现卡片与详情，容易出现操作和缺图处理差异。
- 沿用共享结果组件及现有封面、抽屉，让详情读取页面快照，收藏状态独立补充。

## 决定

采用共享结果组件的「列表 / 封面网格」双视图，列表沿用 ResultCard 的链接与行内展开，网格复用现有封面卡，两者均可打开通用详情抽屉。详情内容取自当前页面结果，只有本地收藏页使用收藏快照；备注和归属依赖本地记录，普通内容详情不依赖收藏。历史继续只提供查看与删除，不增加收藏功能。关键词、统计和状态页面不纳入。

2026-09-28 调整：列表和网格的收藏信息统一放入已有详情抽屉，移除列表重复的信息条；收藏成功后两者均直接打开归属面板。列表封面以摘要区常见高度为基准定高，列表与网格都统一为 16:9 裁剪铺满，以保持行列整齐，用文字阴影代替整条深色遮罩，避免留白图框和重遮罩破坏封面观感。

视图偏好按搜索、历史、本地收藏、跨平台汇总和平台收藏夹内容分别保存，默认网格。它与旧文件夹导航偏好分开，不联动其他页面；切换不重挂载结果区，不重置筛选、排序、页签、批量选择或已显示条数。文件夹根页不提供内容视图切换。

## 后果

列表保留直接阅读与行内展开，网格通过详情查看完整信息，维持各页面已有操作边界。卡片常驻原文与适用动作，抽屉保留完整详情和收藏管理；只打开详情不计入观看历史，原文链接按实际来源记录。无需更改后端、抓取、数据或备份格式。
