# 决策：内容网格与独立于收藏的详情

- 日期：2026-09-27
- 状态：采用并实施
- 相关：[搜索体验](../features/search-experience.md)、[本地收藏](../features/favorites-library.md)

## 背景

用户要求把本地收藏认可的封面网格推广到内容结果页，并移除本地收藏列表和侧栏。搜索、历史与跨平台归档并不一定存在个人收藏记录。

## 选项

- 各页面单独实现卡片与详情，容易出现操作和缺图处理差异。
- 沿用共享结果组件及现有封面、抽屉，让详情读取页面快照，收藏状态独立补充。

## 决定

采用共享结果网格，复用现有封面卡与抽屉，不新增浏览方式切换。详情内容取自当前页面结果，只有本地收藏页使用收藏快照；备注和归属依赖本地记录，普通内容详情不依赖收藏。历史继续只提供查看与删除，不增加收藏功能。关键词、统计和状态页面不纳入。

## 后果

详情多一步打开，但保持浏览位置和各页面已有操作边界。卡片常驻原文与适用动作，抽屉保留完整详情和收藏管理；只打开详情不计入观看历史，原文链接按实际来源记录。无需更改后端、抓取、数据或备份格式。
