# 决策：空间 AI 分区读取与可选本地转写

- 日期：2026-10-04
- 状态：已实施；真实媒体、模型和冻结安装包兼容性待实测
- 相关：`docs/features/space-research-ai.md`

## 背景

整条资料 JSON 混合切段使模型难以定位评论和字幕，只读前段却可能引用整条资料。无平台字幕的视频则缺少讲话证据。希望在现有平台访问、安全工具和隔离研究任务内解决，不增加另一套爬虫或强制重型依赖。

## 选项

- 保留整体切段并扩大首段：仍不能解释各部分的读取覆盖，且会扩大 prompt。
- 引入向量库：增加依赖、索引与维护成本，此轮定位明确的资料不需要。
- 将 ASR 和模型直接打包：安装包与运行内存显著增大，影响未使用视频研究的人。
- 分区工具访问，加独立可选 ASR worker：复用既有任务状态和平台 client，缺失时可降级。

## 决定

采用最后一项。正文、评论、字幕各自分页并独立计数，保留来源级引用，把各部分实际读取比例附在引用记录中；不宣称程序可以判定模型的语义理解。简单关键词检索可将来叠加在同一分区访问层，无需先做向量数据库。

优先原生字幕，有部分字幕时保留其缺口，不自动替换为 ASR。无字幕时使用平台已有媒体资源，B站请求独立音轨，小红书、抖音只有合并流时限额下载并只解码音轨；知乎现有模型没有媒体地址，先降级。暂不引入 yt-dlp 或脚本提取播放器资源。

转写采用 faster-whisper 固定 small / CPU / int8 / VAD，自动语言检测配中文提示。进程只收到临时媒体路径及固定识别配置，不接收会话、模型服务凭证或可调用工具。引擎由用户手动安装到独立运行环境，模型首次实际使用时下载，主安装包只包含小型 worker 和安装脚本。

## 后果

- AI 清单可发现各区段；读取正文后，评论与字幕依然明确未读。来源级标识保持兼容，但不能机器验证「某句话是否来自某个区段」。
- 安全下载不发送 cookie；依赖登录的 CDN 可能无法转写，保留正文和评论是预期降级。
- 文本缓存有身份／设置区分、有效期和容量上限；失败不缓存，临时媒体由父任务管理生命周期，模型不随结果淘汰。
- 多分集 ASR 只覆盖主分集；CPU 长视频、首次下载仍受既有十分钟任务预算约束。后续应先实测，再考虑分集调度和下载进度细化。
- PyInstaller 排除引擎与大型 DLL；冻结环境使用独立 Python，避免在主进程动态加载另一套二进制依赖。需补干净 Windows 安装验收，未启用 ASR 的默认路径不增加模型下载。
