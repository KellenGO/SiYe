# 收藏同步分页与账号边界

## 背景

收藏接口分别使用页码、offset、字符串 cursor 和数字 cursor。错误地把它们统一成页码会在短页、重启或接口漂移时跳项；账号归属也不能从收藏内容反推。

## 选项

1. 为每个平台各写一套任务和 SQLite 表。
2. 共用保存、检查点和基线规则，只让平台层解释账号、列表和分页令牌。

## 决定

采用第二项。检查点保存 JSON 编码的原始令牌，列表完成才独立提交基线。自动同步只查询本轮开始前的、同账号同列表的基线；页内达到连续五条后仍保存整页。没有已验证账号身份的抖音全量路径保持关闭。

## 后果

页面入口和 V0.3 展示不增加新操作。知乎、小红书可使用当前接口进行分页导入；抖音仍保留原有有限读取，待客户端提供稳定的当前账号接口和只读探测证据后再启用全量。

状态：已采纳
