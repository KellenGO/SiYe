# 决策：小红书热搜使用匿名第三方榜单

- 日期：2026-10-18
- 状态：已实施
- 相关：`docs/features/trending-board.md`

## 背景

小红书热搜此前未接入，前端也固定隐藏其词条。官方旧热榜匿名请求返回 HTTP 406 与空数据；
网页热词匿名加签请求虽返回 HTTP 200，业务码仍为缺少登录信息。用户明确选择接受公开第三方热榜并注明来源，
同时明确不使用本机登录态。

## 选项

- 保持暂不可用，等待官方提供稳定匿名入口。
- 复用登录态或浏览器获取官方数据：需要维护会话和互斥，且不符合用户本次明确约束。
- 使用可匿名访问的第三方聚合榜单，标明来源与更新时效边界。

## 决定

采用 [UApiPro 公开热榜](https://uapis.cn/docs/api-reference/get-misc-hotboard)，固定查询小红书榜单。
接入前匿名实测通过，并核对响应的平台身份；错误、空榜或其他平台数据都不作为成功结果。
不引入新依赖，不发送登录态、搜索词或用户资料。来源由本机固定配置提供，成功、缓存命中和失败时均可追溯；
界面用「来源：UApiPro（第三方）」链接标注，显示所选平台提供的更新时间。

保留启动取一次与用户手动刷新的时机，不做轮询，不改变搜索冷却或账号状态。

## 后果

- 小红书榜单的可用性与更新速度依赖第三方；本机刷新不能保证来源刚更新。
- 来源失败只影响小红书，不能退回登录态或付费服务，也不把个性化推荐词伪装成全站热榜。
- 此接入不代表小红书官方匿名接口已经恢复；未来替换来源时应重新验证并同步界面标注。
