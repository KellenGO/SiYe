# 决策：自建收藏夹的简介与封面保存在本机收藏库

- 日期：2026-09-26
- 状态：**已实施**
- 相关：`docs/features/favorites-library.md`

## 背景

用户希望在左侧收藏夹菜单打开编辑卡片，同时修改名称、简介和自选封面。原本的封面只从夹内内容缩略图自动推断，收藏夹本身没有简介和图片数据。

## 选项

| 方案 | 优点 | 代价 |
|---|---|---|
| 图片存入 `library.db`，导出备份时嵌入图片 | 随数据库和现有 JSON 备份迁移，不会留下孤立文件 | 数据库及备份体积增加 |
| 图片单独存放在数据目录 | 数据库较小 | 备份、迁移和删除都要管理第二份文件 |
| 只保存在浏览器 | 实施简单 | 换浏览器或清理缓存后会丢失 |

## 决定

采用第一种。上传图片限制为 5 MB，由后端验证格式、缩放到最大 1200×1200 并转成 JPEG，再保存在收藏库。列表只返回带版本标识的封面地址，图片由单独接口读取，避免每次刷新都把图片编码塞进收藏夹列表。备份格式升级到 v5，保留旧版导入支持。

## 后果

- 用户封面优先于内容自动封面；移除自选封面后恢复自动封面。
- 图片会增加本机数据库和备份文件大小，但单张经过尺寸和大小限制。
- 不增加公开状态；本地收藏夹仍只在本机使用。
