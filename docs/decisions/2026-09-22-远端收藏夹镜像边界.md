# 远端收藏夹镜像边界

## 背景

跨平台归档已有内容和归属，但页面无法按真实远端收藏夹浏览。

## 决定

在同一 SQLite 中保存只读远端目录，身份为平台、稳定账号与远端夹 ID；内容继续复用既有归档与归属表。目录成功与内容扫描成功分开记录。B站、知乎在收藏页以封面卡片网格进入逐夹分页浏览，全部内容与未归属旧内容仍作为非真实夹入口保留。小红书单一收藏流不冒充多夹，抖音在可验证账号身份缺失时不启用镜像。

## 后果

本地可编辑收藏夹与远端镜像不互相导入或修改。知乎内部身份以类型加数字 ID 保护同号内容；历史已经覆盖的记录无法恢复。封面不用发布时间猜测收藏顺序，优先使用同步基线顺序，缺少可靠时间时退化为最近一次同步页中首张有效封面。

状态：已实施（B站、知乎）；小红书真实目录与抖音账号/目录能力仍待真实只读验证。
