# 决策：平台偏好的空数组就是「零勾选」

- 日期：2026-09-23
- 状态：**已实施**
- 相关：`docs/features/search-experience.md`、`docs/features/getting-started.md`

## 背景

搜索页的平台按钮是勾选框，设计意图与教程文案都是**默认一个都不勾，由用户亲手勾**
（用户的原话：这样他就知道可以在这勾选了，并且一勾都不勾时点搜索会提示先选平台）。
实测：在首页 →「设置」→ 回到搜索页，或刷新一次，四个平台会变成全部勾上。

## 关键事实（决定了选项空间）

- `readPlatformPref` 在存储里**没有这个键**时返回空集（首次进入允许零勾选）。
- `SearchPage` 挂载后，`useSearchExperience` 的持久化 effect 会把当前 `platformPref`（此时是 `[]`）写回存储。
- `parsePlatformPref` 原本对"过滤后为空"的输入**回退全选**（本意是：存储损坏时别把用户卡在零勾选上），
  于是 `"[]"` 再读出来就成了四个平台全选 —— 只在页面往返或刷新后暴露，首屏看不出来。
- reducer 的 `platform_pref_set` 在收到空集时**保留已落地的旧偏好**（UI 允许手动取消到零，提交时统一提示先选平台），
  所以存储里的 `"[]"` 只可能来自"还没有落地过偏好"，不会来自"用户把偏好清空了"。
  （**这条后来被推翻了，见文末「同日补充」**：保留旧偏好会让存储和界面分叉。）

## 选项

| | 做法 | 代价 |
|---|---|---|
| **A** | `parsePlatformPref` 对**显式空数组**返回空集；非数组 / 全部非法仍回退全选 | 少了一条"空数组也算损坏"的兜底（但空数组本来就不是损坏） |
| B | 首屏不写回空偏好（仅在偏好非空时写存储） | 要区分"从未落地"与"用户清空"，而 reducer 本就保留旧偏好，改动更绕 |
| C | 保持现状，把教程文案改成"默认全选" | 与设计意图相反；用户明确要的是"全不勾，让用户自己勾" |

## 决定

选 A。语义说清楚：**空数组 = 还没有偏好记录（= 零勾选）；非数组或全部是非平台值 = 存储坏了（= 全选兜底）**。

## 后果

- 页面往返、刷新后平台保持零勾选；损坏值仍兜底全选，不会把用户卡住。
- `scripts/getting_started_smoke.py` 原先依赖"往返后变成全选"才能跑通，现改为显式勾选小红书，
  并修掉那条把它误读成"教程会预先勾上已连接平台"的注释。
- 新增前端用例：`parsePlatformPref([])` 返回空集、空偏好写回再读仍是空集。

## 同日补充：用户把平台全取消，也要算「上一次的选择」

上面「关键事实」第 4 条与 B 选项都默认了 reducer 会**保留已落地的旧偏好**，于是一个漏洞
只有在这条假设下才成立：存储里可能出现"用户清空了、存储却还留着旧的"这种分叉。

- 实测（隔离浏览器，逐条读 localStorage）：勾小红书 → 刷新，小红书勾着（符合预期）；
  再勾知乎 → 刷新，两个都在（符合预期）；**把两个都取消 → 存储仍是 `["zhihu"]`，刷新后知乎自己勾回来** ——
  界面是零勾选、存储是旧值，用户没做过的动作被系统补上了。
- 这条"至少留一个平台"的规则还和 UI 自相矛盾：SearchBar 允许取消到零，也允许零勾选时点搜索
  （只提示"先勾选至少一个平台"，不禁用按钮），首次进入本来就是零勾选 —— 零既然是合法状态，就不该拒绝落地。
- 影响面不止手动取消：平台搜索失败时 `SearchPage` 会自动取消这些平台的勾选，旧规则会让它们在刷新后
  又"恢复"成已勾选，而用户刚被告知"已自动取消勾选"。

| | 做法 | 代价 |
|---|---|---|
| **A** | `platform_pref_set` 照单全收（含空集）：**偏好 = 用户最后一次的勾选** | 少一条"至少留一个平台"的不变量；零勾选后的提示由 SearchBar 承担（已有） |
| B | 维持旧规则 | 存储与界面分叉：用户取消过的平台会在刷新后自己勾回来；与"零是合法状态"矛盾 |

选 A。规则收敛成一句话：**偏好就是用户最后一次勾的样子，含"一个都不勾"**。

- 前端用例 `⑭` 由"空集保持已落地偏好"改为"空集照常落地"，并补上"零偏好写回存储再读仍是零"。
- `platform_pref_set` 的注释与 `parsePlatformPref` 的文档注释同步改口径（原文写着"至少保留一个平台"，已过时）。
- `scripts/getting_started_smoke.py` 新增两条常驻断言：勾选后刷新仍是那个平台、取消到零后刷新仍是零。
