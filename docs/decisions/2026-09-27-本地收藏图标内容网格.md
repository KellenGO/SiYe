# 决策：本地收藏图标模式延续封面网格

- 日期：2026-09-27
- 状态：采用并实施
- 相关：[本地收藏夹](../features/favorites-library.md)

## 背景

此前图标模式仅覆盖收藏夹根页，进入后变回带侧栏的纵向列表。用户选定 A 的网格与详情抽屉方向，并明确保留列表模式及切换，要求点击抽屉外部空白也能关闭。

## 选项

- 网格配详情抽屉：保持浏览位置，卡片上少量信息，按需查看完整内容。
- 网格配独立详情页：窄屏空间充分，但查看多条内容需要反复返回。
- 网格常显较多数据与简介：便于比较，但降低封面的突出程度并增加卡片高度。

## 决定

采用网格配详情抽屉，只应用于本地收藏的图标模式。根页保留原封面堆叠、比例与数量角标；内容页去掉左侧收藏夹列表，通过返回入口回到根页。列表模式维持原浏览与管理方式。

卡片呈现封面、类型、标题与平台，完整简介、已有指标、备注和归属放在抽屉。关闭方式包含外部空白、Escape 与显式按钮，未保存备注需确认放弃。窄屏使用全宽抽屉，保留按钮与键盘关闭。原平台链接单独提供，打开详情不产生观看记录。

## 后果

封面浏览更连贯，详细数据多一步操作；窄屏打开详情会暂时遮住网格。图标根页用显式前移/后移整理收藏夹顺序，内容页保留编辑与新建入口，避免移除侧栏后丢失管理能力。沿用现有本地数据、筛选、批量操作和导出，不改变后端、备份格式或跨平台收藏界面。
