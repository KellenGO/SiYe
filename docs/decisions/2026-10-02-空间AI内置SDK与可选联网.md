# 决策：空间 AI 使用内置 SDK，联网按空间可选

- 日期：2026-10-02
- 状态：已实施；真实平台与付费服务仍待验收
- 相关：`docs/features/space-research-ai.md`

## 背景

空间的价值在于用户自己选择跨平台信息来源，并把这些资料整理成一份研究笔记。普通模型 API 不会自动读取平台帖子、评论或字幕，需要应用提供资料获取与工具循环。用户希望普通 Windows 安装包直接使用这一能力，同时保留可选联网补充。

## 选项

- 直接调用模型 API，由四野实现全部分段与工具循环：依赖少，但需要自行维护循环、工具协议与长资料处理。
- 依赖用户安装 Claude Code 插件或 CLI：开发成本较低，给普通用户增加环境与认证步骤。
- 内置 Claude Agent SDK 及官方运行程序，四野提供受控资料工具：增加包体积与运行程序维护成本，保留成熟工具循环并减少用户安装步骤。

## 决定

采用内置 SDK，使用用户配置的 Anthropic 兼容 API 密钥。固定 SDK 与 Windows 运行程序版本，构建下载时校验完整性并带上上游许可与说明。不开启订阅登录或本机通用编程工具。

空间资料由四野读取并分段提供，AI 只获准访问本次快照。联网默认关闭，按空间独立保存；开启后使用框架搜索与四野受控网页工具。选择自定义网页工具以检查公开地址、跳转与正文读取程度。外部依据单独分节，并区分搜索摘要和正文，避免把补充资料误认为用户选入的来源。

生成先预览、后追加；沿用现有笔记版本控制、自动保存和撤销机制。一个应用同时只有一个研究任务，任务运行于独立进程，累计处理最多十分钟，等待确认不计时。

## 后果

- 安装包明显增大，发布构建依赖 npm 官方运行程序下载；运行程序版本升级需重新验证工具权限、进程清理和冻结打包。
- 用户仍需提供可用 API 服务，第三方服务不能仅凭文字生成能力认定兼容；连接测试要实测工具循环，联网模式还要实测搜索与网页读取。
- 平台会话与访问限制由抓取适配处理，SDK 不保证匿名访问或字幕存在。缺失项和未读分段成为可见结果的一部分。
- 单次生成涉及多轮模型请求。实际费用由服务商决定；保持用户主动开始、确认资料及追加笔记。
- 可取消与冻结程序验收已经具备隔离 smoke，真实账号资料和付费服务需要另行验证。
