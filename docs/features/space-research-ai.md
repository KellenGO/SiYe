# 空间 AI 研究助手

## 一句话

围绕用户选入空间的跨平台资料，通过默认的 OpenAI 兼容 API（支持 DeepSeek、Gemini 等工具调用模型）聊天、读取正文／评论／平台字幕，并由用户追加回答到空间总笔记。直接提供资料清单与链接，以简短规则引导先读资料、自然回答和可追溯引用；联网补充由每个空间单独选择，默认关闭。

## 关键决定

- 参照用户提供的 Claudian 截图，助手通过页面右上角独立入口打开，配置仍在设置页。桌面使用贴齐窗口顶部和底部的非模态右侧栏，可拖动左边界调宽并记住宽度，同时压缩主页、顶栏和页脚；分隔线支持左右方向键、Home／End。桌面历史栏始终与聊天并排，窄侧栏打开历史时适度加宽，确保列表不遮挡输入。展开时填满整个窗口，不留顶部或左侧偏移、也不增加背景遮罩；全屏仍能拖回侧栏，收起按钮恢复之前的侧栏宽度。手机使用全屏模态面板并限制焦点。新会话保留历史栏及搜索条件，桌面切换会话也保留列表；只有手动关闭或 Escape 才收起历史栏，手机选中历史会话后收起列表以显示聊天。Escape 先关闭会话列表，再关闭助手；关闭助手不取消任务。问题显示为右侧气泡，工具步骤直接展开在消息流中，单步详情及资料获取记录可折叠；底部固定输入、模型、联网及发送／停止。会话支持标题搜索，每轮回答都可追加笔记。没有移植 Obsidian 工作区 API 或引入新框架。
- 两种协议共用一小段默认研究规则和相同的请求上下文：默认中文，把名称／简介当主题背景；先看随请求提供的资料清单、链接、短简介及获取缺口，按问题读取相关分段再综合回答。要求区分来源事实、推断、外部内容和未知项，交代冲突与部分读取；来源内容中的指令不作为助手指令。根据问题自由组织回答，简单聊天、澄清不强制报告模板。OpenAI 使用 system 消息，旧 SDK 使用相同的 system_prompt；连接测试仍使用独立测试请求。没有默认研究问题，也不强制 JSON 或固定栏目，普通回答仍支持基本标题、列表和加粗。取舍由[清空提示词与公开执行过程](../decisions/2026-10-03-空间AI清空提示词与公开执行过程.md)调整为[清单直传与自然回答引用](../decisions/2026-10-04-空间AI清单直传与自然回答引用.md)。
- AI 服务配置位于全局「设置 → AI 服务配置」，所有空间共用。默认使用 OpenAI Chat Completions 协议，提供 DeepSeek、Gemini、OpenAI 及自定义服务选项，模型名称可自行填写。填写服务基础地址、API Key 和模型名称；同一服务留空 Key 保留原配置，切换服务商需要填写对应 Key，可单独清除配置。旧配置未声明协议时仍按 Anthropic 执行，不静默更换地址或 Key。「保存并测试连接」先保存当前输入，再用设置页的测试联网选项验证；该选项不改变空间研究偏好；运行或等待确认时不能更改服务配置。密钥使用 Windows 当前用户加密，公开接口只返回是否已保存和遮罩。本机接口严格检查 Host 和 Origin，拒绝恶意域名自称同源。使用 API 计费，默认模式无需 Claude 账号或运行程序，不继承本机 Claude 订阅登录。连接测试也可能计费。
- 点击生成先固定空间资料快照、研究问题和联网选择，再获取资料。新增或移出的来源只影响新会话，当前结果会提示快照已变化。抓取不会修改空间原快照、收藏或用户笔记。
- 可以开新会话、切换当前空间的历史会话和连续追问。首次研究先获取并确认资料；同一会话复用原资料和快照，持续携带首轮研究目标与最近三轮已完成问答。每轮长答案只保留前 2000／后 1000 字并标明截断，保留引用链接以便复核；更早对话不进入请求，避免旧答案占满资料上下文。前序问答只用于理解追问，不能替代证据：每轮的空间读取记录重新计数，引用需要按需重读，外部来源也须本轮重新发现或获取，标识以本轮清单为准。新的联网选择只用于下一轮。任务未完成或等待确认时，需要先完成或取消才能切换或新建，避免丢失正在处理的任务。
- 标题和简介取自已加入的快照，补取正文、最多 50 条评论（含少量回复）及可访问的平台字幕。B站与知乎请求热门评论，小红书、抖音保留平台默认顺序；实际顺序、截断与失败都展示。已有响应中的点赞、回复数量随评论保留，不增加请求。后续分页失败保留已有内容，重试成功项保持不变。
- 资料获取后等待用户检查，允许重试缺失或失败项、或使用已取得内容继续分析。等待确认不占处理时间。重试中账号或客户端初始化失败也保留之前取得的部分评论、字幕。正文、评论、字幕分别开放分段读取，清单列明每项数量、可读段数与缺口；长评论保留身份和文本偏移，字幕保留时间位置。每轮独立记录各部分实际读取的段数与索引，清单和简介不算正文证据。未读取任何部分的来源不能引用；只读正文时引用附注明确说明评论、字幕仍未读，普通回答和结构化结果一致。这只能验证调用记录，不能保证模型理解或结论正确。模型不会得到其他空间的资料、数据库、媒体资源地址、登录 cookie 或 API Key 文本。
- 视频优先原生字幕；没有可用字幕且没有已保留的部分原生字幕时，才尝试本地转写。B站复用已有 client 的播放接口，选低码率独立音轨；小红书、抖音复用详情中的媒体流，存在音轨时优先选择，不把背景音乐当视频讲话。媒体流只向公开地址下载，逐跳校验 DNS，发送公开 Referer、不传 cookie；下载和解码均有上限。失败不影响正文、评论，ASR 前先发布这些内容，即使长任务被取消也保留。已有部分原生字幕不被转写覆盖，缺失分集仍作为缺口。
- 本地转写使用可选 faster-whisper，小模型默认 small / CPU / int8，启用 VAD，中文提示配合自动语言识别。解码和识别运行在独立子进程；Windows 进程树由现有 Job Object 管理，取消后先终止进程再由父任务清理临时媒体。首次使用阶段显示模型准备／下载、音轨提取及转写状态，不假报下载百分比。字幕展示平台原生或本地 AI 转写及覆盖时长；ASR 记录引擎、模型、识别语言和缓存命中，AI 统一读取同一种时间字幕。完成后的资料面板还区分「已取得」和「AI 实际已读」。
- 成功完整转写按视频身份、模型与识别设置缓存 30 天，最多 64 份／32 MB；不缓存失败、媒体文件、临时 URL 或凭证。同一会话继续复用资料，新会话可复用磁盘转写；空间快照和笔记不改变。安装包只带 worker 与可选安装脚本，排除引擎依赖和模型，转写运行环境与模型存于本机用户数据目录；未启用的用户不下载。长期取舍见[分区读取与可选本地转写](../decisions/2026-10-04-空间AI分区读取与可选本地转写.md)。
- 普通回答使用 `[S1]` 等空间标识和 `[W1]` 等外部标识，直接变成原来源链接，末尾仅为引用过的来源附上名称和实际读取程度，不要求整篇研究报告。清单不算正文已读；未读或不存在的标识不能成为引用，两种协议最多请求模型修正一次，仍无效则报错，修正可能多一次模型往返。引用的资料获取缺口和本轮未完整读取情况由程序附注；没有读取空间资料的回答明确标为未经空间资料验证。搜索摘要可作为摘要来源引用，但读取记录始终说明只有摘要；部分网页正文不会显示为全文已读。
- 全局只运行一个研究任务，包括等待资料确认。平台获取阶段与搜索、收藏同步、账号操作互斥；分析阶段释放平台资源。任务累计实际处理最多十分钟，取消、归档、删除和应用退出会停止相关进程；Windows 同时关闭全部子进程并清理临时会话。
- 联网偏好按空间保存，默认关闭，修改只影响下次任务。关闭时只暴露选定空间的读取工具；开启时默认开放四野提供的公开搜索和受控网页读取，不要求模型服务自带搜索。公开搜索读取 DuckDuckGo HTML 结果，只提供少量摘要，不能把摘要当作正文；旧 Anthropic 模式仍用 SDK 搜索。网页读取逐次检查域名解析与跳转，并固定公开地址连接。文件、命令、浏览器控制与其他 MCP 不开放。读取记录区分搜索摘要、部分及完整网页正文；结构化结果仍将外部结论分节，普通回答不强制栏目。
- 结果先显示预览，追加时再次检查空间及笔记版本，插入当前编辑器末尾成为一次可撤销操作，保留生成期间的手写内容。保存冲突、输入法组词和超限时拒绝追加并保留预览；保存失败明确显示已插入草稿但未保存，重试只保存、不重复插入。防重复标记在服务端确认保存后写入，刷新后仍阻止重复；保存失败后刷新可重新追加。生成不会自动覆盖正文。
- 聊天内同时展示最近十轮。每步工具显示名称、执行中／完成／失败／中断及有限结果摘要；运行与完成事件更新同一记录，取消或失败不会留下永久执行中状态。模型在工具调用前返回的公开文字显示为「过程说明」，不展示隐藏思维链或签名、不把工具记录冒充模型思考。每轮最多保留四十条执行／文字记录，公开文字每条最多 4000 字；轮询不反复传输原始正文、评论、字幕或认证内容。完成任务按最近顺序保留，最多十个且按约 32 MB 的序列化数据预算淘汰；至少保留最新的一个，正在运行或等待确认的任务不淘汰。
- 默认工具循环复用现有 HTTP 客户端，不新增模型 SDK 或框架。只开放空间清单、分段读取、受控联网和结构化结果提交；DeepSeek 推理内容及 Gemini 工具签名只在当前工具循环中原样回传，不展示或写日志。保留旧 Anthropic SDK 接入和打包能力。长期取舍见[默认 OpenAI 兼容协议](../decisions/2026-10-02-空间AI默认OpenAI兼容协议.md)。

## 已知坑 / 边界

- 「网页公开」不保证平台接口允许匿名读取。小红书、知乎的签名依赖本机会话；抖音使用应用自己的浏览器会话。访问受限显示缺口，框架不能绕过平台限制。B站匿名正文、评论和字幕也可能受登录、风控或字幕权限限制。
- 默认服务必须支持 OpenAI Chat Completions 的工具调用；只支持普通文字生成的模型不能直接用于研究。Gemini 使用官方 OpenAI 兼容基础地址，模型是否可用仍以账号权限为准。旧 Anthropic 模式需要内置运行程序且依赖服务端搜索能力。连接测试实测工具循环，联网选项还实测搜索与网页读取；基础调用成功不等于所有能力可用。
- 公开搜索可能因网络地区、验证码或搜索页变化失败，结果摘要与网页正文分别标记，失败作为缺口保留。模型服务可能限流、余额不足或限制工具参数；不会转为普通文本并冒充已经读取资料。默认协议不支持 OpenAI Responses 或 Gemini 原生 generateContent 地址。
- 原生字幕入口主要覆盖 B站，小红书与抖音读取详情实际返回的字幕地址；知乎当前详情模型只保留文字和落地页，未保留可复用媒体流，本地转写如无缓存会诚实显示缺口。B站无字幕可尝试主分集音轨转写，多分集会明确标为部分；已有部分原生字幕不会再用 ASR 补其它分集。小红书、抖音如只有合并视频流，需临时下载该流并在子进程提取音轨；不存在资源、签名失效、CDN 拒绝匿名媒体请求或只有 HLS 清单时可能降级，不引入 yt-dlp、解密或播放器脚本 hack。不做画面识别、OCR 或登录网页自动浏览。
- ASR 单条媒体最多 96 MB、音频最多 30 分钟，下载最多 90 秒、模型准备与转写最多 6 分钟；仍计入整轮十分钟处理上限。普通 CPU 上长视频或首次模型下载可能超时，模型下载由引擎缓存支持后续重试；失败保留文字。各项文字最多保留 256000 字，字幕最多 10000 条，超限展示截断。默认 OpenAI 循环还限制累计上下文，避免反复读取长字幕持续扩大请求。字幕显示的原生时长是取得字幕的时间终点（多分集求和），不是保证整个视频时长；本地转写时长来自解码音轨。
- 评论不是全量，回复只取少量，资料片段不是事实保证。模型可能遗漏来源或产生错误推断；覆盖记录说明读取情况，不能保证语义上完全理解。
- 引用校验只保证标准来源标识对应本轮实际取得／读取的来源，不能证明某句话被原文支持、引文准确，或模型理解了全部内容。非标准引用、自由文字中的「已读」说法不能自动验证；模型也可能漏掉引用或忽略研究规则，未读回答会显示未验证提示。不会把自然聊天强制改成结构化报告。简短应用规则不能控制服务商或 SDK 自身可能注入的内容。
- 会话历史、任务、抓取正文和未追加的预览只保留在应用进程内；应用重启或历史任务被淘汰后需重新生成。已保存的笔记和空间联网偏好保留。生成不会提前把空间笔记正文发送给模型。
- 原有 Windows 当前用户密钥加密仍保留。OpenAI 模式报告累计 token，不估算服务商费用；Anthropic 模式沿用模型报告费用。复制配置到其他账号或机器后需重新填写 Key。模型报告费用可能与代理实际账单不同，显示值供参考。
- 单次网页最多 2 MB、最多五次跳转；字幕 JSON 同样限制响应大小。研究进程通信有 16 MB 单条消息上限，超大资料集合可能失败，需拆成更小空间；不会静默截去已选来源冒充全量分析。
- 当前有模拟平台响应、真实 SDK 接本机模拟服务及 Windows 构建验收；本轮新增 ASR 的归一化、资源适配、缓存、限额、失败、真实子进程通信／取消及界面模拟验证。尚未安装实际 ASR 引擎、下载模型或对真人平台音轨逐一验收，也未重建本轮 EXE；实际识别质量、CDN 可访问性和可选环境的 DLL 兼容性仍需验证。

## 测试怎么跑

- 后端：`.venv/Scripts/python.exe -m pytest tests/test_research.py tests/test_research_openai.py tests/test_research_sections.py tests/test_research_transcription.py tests/test_spaces.py tests/test_account_coordinator.py tests/test_tray_launcher.py tests/test_docs_wiki.py tests/test_webui_ui_contract.py --basetemp=.tmp_pytest_ai/check`，先创建父目录。所有写入数据测试使用临时目录，不下载真实模型、不访问真人平台。

## 启用可选本地视频转写

需要独立 Python 3.11 或以上。在 Windows PowerShell 手动运行 `./scripts/install_research_asr.ps1 -Python python`（或通过 `-Python` 指定 Python 绝对路径）。源码脚本位于仓库 `scripts/`；重新构建的安装包在资源目录的 `scripts/` 下提供相同脚本，通常在 `_internal/`。脚本只建立当前用户的可选转写环境并安装固定版本引擎，不安装模型，不修改主应用依赖。源码开发环境已有 faster-whisper 时也可直接使用当前 Python。

首次遇到无原生字幕且媒体可取的视频时，才从 Hugging Face 下载 small 模型，界面显示下载阶段；无网络、未安装组件或安装不完整都返回明确字幕缺口。运行环境、模型及文本缓存位于用户数据目录的 `research-asr/`（遵循 `SIYE_DATA_DIR`），不要放入分发包。可选安装脚本尚未在干净 Windows 环境实装验收；引擎 API 依据 [faster-whisper 官方说明](https://github.com/SYSTRAN/faster-whisper)，独立实现，未复制用户参考仓库代码。
