# 内容站内阅读与视频播放

## 一句话

小红书图文／视频、抖音图集／视频、B站普通视频及知乎回答／文章可以在四野详情面板或全屏阅读、播放，沿用当前主题，并保留原文入口。

## 关键决定

- 平台资料、浏览器会话和公开地址检查属于基础程序的共享能力，未安装或关闭 AI 扩展仍可站内阅读。
- 研究采集可读取同账号本次运行已保留的知乎正文，不额外触发阅读请求或启动第二个浏览器；抖音研究与阅读共用匹配内容的官方页面取数。阅读入口仍按需加载，不因共享能力而自动抓取评论或启动语音识别。

- 参照 [OpenScope](https://github.com/metaMMY07/OpenScope) 的「平台取数与自身展示分离」思路，在现有 React 详情面板增加阅读能力，不引入 Flutter、播放器框架或新的依赖。取舍见[站内阅读从知乎开始](../decisions/2026-10-10-站内阅读从知乎开始.md)。
- 可信且身份匹配的上述内容在列表中点击标题或封面进入阅读；网格沿用详情入口。搜索、收藏、历史及空间资料共用同一详情面板。其它内容保持已有信息展示与原文入口。
- 详情顶栏的「全屏查看」占满当前窗口，正文保留适合阅读的宽度，空间笔记仍可并排编辑；「退出全屏」恢复抽屉。切换沿用同一正文、播放器与笔记，不重新取数或重复记录历史，保留字号、播放进度及编辑记录。Esc 先退出全屏，再次按下关闭详情；嵌套确认和菜单优先处理自身退出。
- 仅在打开详情时额外获取正文，不在搜索列表批量预抓。知乎搜索响应已经带有正文时，经私有 worker 事件送到后端，去掉脚本并分块后在本次运行保留；点开同一账号下的回答／文章直接复用正文及图片。摘要不进入正文缓存；权限拒绝、空正文及超限内容不保留。去掉搜索来源的统一“不完整”提示，只在平台明确标记或解析实际截断时提示，不因取消提示而保证所有回答都是全文。取舍见[复用知乎搜索自带正文](../decisions/2026-10-11-复用知乎搜索自带正文.md)及[知乎问题式阅读](../decisions/2026-10-11-知乎问题式阅读与运行期正文.md)。
- 搜索问题详情先展示已经取得的回答，再按问题标题、赞数排序补充一页；每次“加载更多”只继续一页，严格核对问题编号并按回答编号去重。列表按已获取回答的赞数排列，同赞保持获取顺序，每条单独展开正文和评论，收藏／稍后再看／空间资料及观看历史始终对应具体回答。原有回答收藏直接进入该回答，不改成问题收藏。
- 问题信息和回答互动分开：回答显示自己的赞、评论、收藏，不展示口径不明的浏览量；旧收藏的同类浏览量同样隐藏。问题浏览量和回答总数只采信明确的问题字段；搜索里的总回答数零值占位不展示，不把“已加载”解释成总数。补充回答不改原关键词搜索的分页、排序及卡片数量。
- 无可用搜索正文时，知乎复用 Accounts 登录态和现有签名客户端，请求 UA 取自本次实际浏览器上下文；接口拒绝或结构异常时直接打开目标回答／文章，不先访问首页。等待最多八秒取得匹配 ID 的正文，明确权限拒绝不回退；导航 403／412／429 归为验证或访问限制，不误报正文权限。主动重新读取仍请求平台，失败保留已经显示的正文。
- 小红书复用详情接口和已有登录浏览器，使用原始内容链接中的访问 token；B站复用详情及播放接口。正文读取不附带评论／字幕或启动 AI 转写。
- 抽屉及全屏共用「展开评论」入口，默认收起且不请求评论。第一次展开自动加载，正文正在获取时等其结束再取评论，无需再次点击；最多 50 条及少量回复，显示平台排序和不完整提示。不写入收藏库、不启动 AI。正文与视频保持显示，失败可重试，刷新失败保留已有评论；关闭面板取消评论请求并释放账号操作租约。收起／再次展开及全屏切换保留评论，不重复请求。
- 默认保持窄阅读抽屉；展开评论时扩宽，可用内容宽度足够时左右各半展示：标题、正文／视频、互动数据及收藏等操作在左侧，评论在右侧并单独滚动。收起后恢复窄抽屉；全屏模式隐藏评论时正文居中。窄屏或空间笔记挤占内容宽度时改为正文在上、评论在下，保留已有正文、评论和播放进度。
- 主评论以独立卡片分隔，作者与赞数独立于正文；已取得的回复按父评论归入卡片内的浅色区域，并标明回复对象。父评论未返回的回复单独展示、明确提示，不因原始列表顺序而误归到相邻评论；圆形字标只是作者名提示，不是平台头像，不额外请求头像或补造回复总数。
- 互动数据保留已知数字及「约」标记，配图标和横向条形图；条长按当前内容已知指标的最大值同比例展示，便于比较数量，不表示互斥占比或时间趋势。真实零值保留，缺失值不补零，不新增平台请求。
- 抖音优先打开目标官方页面，监听它自己发出的匹配详情响应，不另造签名请求。只接受已观察的 `www.douyin.com`／`www-hj.douyin.com` 详情端点及当前内容 ID；无长度响应由文档开始脚本克隆、流式读取，保留公开字段的有界投影。页面已知状态及严格匹配 canonical、标题和唯一播放器的 DOM 提供补取，不从推荐内容猜正文或视频。最长等待 45 秒，文字先到时继续等媒体；最终只有文字则保留文字与原文提示。取舍见[阅读复用官方页面响应](../decisions/2026-10-10-阅读复用官方页面响应.md)。
- 开始取数前检查后台搜索仍在运行的情况，并停止对应平台的空闲 worker；整个获取过程持有操作租约，避免账号操作、搜索和浏览器 profile 互相争用。正在搜索或处理账号时提供重试提示；缓存命中不访问平台。聚合详情同时有多个可读取来源时，繁忙的来源可逐一重试。
- 只传递段落、标题、引用、代码、列表和可信知乎 CDN 图片。原始 HTML、网页脚本、Cookie、签名和页面状态不返回前端；不把搜索摘要当作正文。付费、隐藏、截断及不支持的嵌入内容明确提示，并保留「在原平台打开」。
- 视频使用浏览器原生控件，点击才开始加载与播放，不自动播放。优先返回 H264 合并媒体流；B站采用普通 MP4、主分集及最多 16 个视频段，可切换段落；抖音图集不播放背景音乐。无法提供视频时仍展示取得的文字，并保留原文入口。取舍见[站内视频使用合并媒体流](../decisions/2026-10-10-站内视频使用合并媒体流.md)。
- 正文默认 18px，可在本次详情调整到 16–24px；刷新失败保留已有内容和字号。可展示正文取得后或纯视频实际开始播放时记一次当前来源的观看历史，刷新不重复记录；读取失败、空的受限正文或关闭尚未完成的请求不记观看。
- 评论展开／收起、字号调整及重新读取合并为阅读工具栏，字号及重新读取在左，评论开关在右，滚动当前内容时固定在详情顶栏下方；空间笔记并排时跟随正文独立滚动区域固定，窄屏允许工具排列换行，不覆盖关闭／全屏按钮。
- 缓存按账号代数隔离，普通详情短时缓存仍最多六项、每项两分钟；知乎已取得正文另外在本次后端运行保留，取消两分钟失效和四十条淘汰，退出／切换账号及关闭程序清理。搜索自带正文单项最多 128,000 字符，内存占用随本次获取量增长。正文不进入公开搜索响应、分页快照、收藏／空间快照或磁盘存档。关闭详情取消前端请求，后端检测断开后取消取数并释放会话及租约。

## 已知坑 / 边界

- 不含弹幕、字幕、图集缩放和完整官方互动。评论只读文字、作者及赞数，回复不完整，不支持发表、点赞或删除；评论接口可能单独受限，正文／视频可读不代表评论可读。标题、作者、时间和指标沿用现有内容快照，读取后不回写这些资料。B站番剧／课程、多分集切换与 DASH 分离音画不支持；不把无声视频流作为可用播放器。
- 站内排版保留文字及图文顺序，行内加粗、链接和编号列表等暂简化为文字／列表项；表格、复杂公式和嵌入媒体提示去原文查看，不承诺复现完整官方页面。
- 登录、验证、平台写操作和受限内容继续在官方页面处理；不会自动过验证码、绕过权限或无限重试。长正文有明确的保留上限和截断提示。
- 知乎图片仍直接读取可信 CDN。其它三平台的图片／视频通过后端短时随机句柄加载，平台签名地址留在后端；请求只发送平台 Referer，不向 CDN 发送平台 Cookie。每次跳转检查平台 CDN 白名单、公开 DNS 并固定连接地址；不接受前端提供任意媒体 URL。保留 Range／HEAD 支持，媒体失效可重新读取；关闭面板停止播放器，断开流会释放连接，不落盘缓存视频。
- 媒体句柄按平台账号代数隔离、最长一小时，容量有界；超期／账号变化／淘汰后旧请求失效。图集最多 60 张，单次图片响应最多 20 MB、视频响应最多 512 MB；过大、加密、HLS、格式不支持或 CDN 拒绝时去原文查看。
- 抖音媒体允许实测的 `douyinvod.com` CDN；官方播放入口仅允许 `www.douyin.com/aweme/v1/play/` 精确路径，跳转后的媒体仍须通过 CDN、公开地址和 MIME 检查。响应监听的 fetch 副本最多 1 MiB；XHR JSON 已由浏览器解析时只能约束保留投影，不能承诺限制原始传输体积。平台自身浏览器请求的完整传输不受副本上限控制。
- 2026-10-10 使用已有账号和少量已保存内容实测：小红书图文正文 879 字及原图、视频正文 156 字及 MP4；B站简介 76 字及主分集 MP4；图片实际返回 200，两个视频的少量分段读取返回 206。小红书及 B站真实播放仍未逐项验收。
- 隔离界面验收使用本机生成的 VP8 测试视频检查播放／拖动／停止；长视频及分段连续播放仍需用户环境验收。现有 EXE 尚未为此重建，源码构建与旧安装包能力不同。
- 2026-10-10 官方页面路径复测：此前抖音样本取得 55 字正文和视频，媒体代理读取 1,024 字节返回 206；独立 Edge 经本机媒体接口播放该 49.8 秒 MP4 成功，并拖动到第 3 秒。旧双重 403 的接口路径已替换，但单条样本不证明所有抖音内容可用。知乎收藏回答在四野 profile 中仍返回 403，文章库暂无样本；用户报告日常浏览器可看，需要同一链接和四野会话的对照才能确认修复效果。没有把请求一致性修正当作知乎线上已恢复。
- 2026-10-11 同一知乎问题真实 API 验收：原搜索命中回答 `14378316462` 为 4 赞／5 条评论，标题搜索补充回答 `1908979197105411082` 为 5436 赞／365 条评论；新问题接口及两条阅读接口均返回 200，分别保留 126 字／4 图、780 字／8 图，没有额外详情请求。两条原始对象的浏览量同为 112,424,515，因此不作为单条回答阅读量展示。用户确认原回答与原文一致，但未逐项验收所有回答的完整性。
- 问题回答列表接口在同一会话仍为 403，本轮默认使用可用的标题搜索，不反复请求被拦接口；标题搜索可能只找到问题的一部分回答，最多二十页或一百条，空匹配页可以继续翻页。风控、超时或繁忙保留已加载内容及游标，允许重试；旧收藏未在本次运行取得正文、程序重启或搜索未带正文时仍可能受限，需要重新获取。
- 评论入口实测（2026-10-10）：只读已有收藏样本，抖音、小红书、B站分别取得 50 条评论，均标为部分结果；小红书 HTTP 461 后已有浏览器补取成功。知乎评论本次未做真实会话复验，不能把入口接入当作其风控已解决。

## 测试怎么跑

- 搜索正文：`tests/test_zhihu_search_reading.py` 检查两条 worker 搜索路径、分页私有传递、正文及图片、摘要不冒充正文、权限／容量／时效／账号隔离、错误任务事件拒绝及公开响应不带正文。
- 问题阅读：`tests/test_zhihu_questions.py` 与 `webui/tests/zhihuQuestions.test.ts` 检查问题归属、两层指标、分页去重、失败保留、游标／账号隔离与加载上限。构建后运行 `scripts/zhihu_questions_ui_smoke.py`，以临时收藏和空间库、模拟平台、独立 Edge 验证高赞顺序、逐条收藏／稍后再看／加入空间、评论身份、失败重试、全屏与 320／390px；截图在 `build/zhihu-questions-ui/`。
- 评论：`tests/test_reading_comments.py` 检查按需获取、来源校验、取消释放及错误隐私；前端评论响应检查在 `webui/tests/reading.test.ts`，`scripts/reading_ui_smoke.py` 验证点击加载、回复展示及全屏保留。
- 后端：`tests/test_reading.py`、`tests/test_reading_platforms.py`，使用 `.venv/Scripts/python.exe -m pytest tests/test_reading.py tests/test_reading_platforms.py --basetemp=.tmp_pytest_reader_<唯一编号>`；覆盖身份、来源、受限／空正文、取数与浏览器关闭、缓存、取消、搜索互斥、本机接口、媒体句柄与 Range／HEAD、重定向／私网阻止、大小和 MIME 限制及异常隐私。
- 页面适配：`tests/test_reading_browser.py` 检查延迟正文、精确响应域、媒体等待、过期路由、验证分类与取消。`.venv/Scripts/python.exe scripts/reading_page_smoke.py` 在独立 Edge 中执行实际脚本，全部页面和网络响应使用替身，验证 fetch／XHR、无长度／超限响应、错配 ID、编码页面状态、大整数精度、图集及严格 DOM；不使用真实账号。
- 前端：在 `webui/` 运行 `npm run test:search` 和 `npm run build`；`webui/tests/reading.test.ts` 检查支持范围、图片与响应身份和安全错误文案。
- 界面：构建后运行 `.venv/Scripts/python.exe scripts/reading_ui_smoke.py`，使用临时 SQLite、模拟平台与独立 Edge，检查列表／网格入口、正文和图片、失败重试、刷新保留、历史、取消、实际视频播放／拖动／分段与关闭、全屏切换保留正文及播放进度、Esc 分级退出、320px／390px 和深浅主题；截图保存在 `build/reading-ui/`。`scripts/spaces_ui_smoke.py` 验证详情全屏切换保留同一笔记编辑器及内容。
