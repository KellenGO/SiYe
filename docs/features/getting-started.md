# 新手引导

## 一句话

首次进入时提供可跳过的邀请，用户主动开始后，在真实页面旁跟随四步提示认识账号、搜索、收藏和帮助。

## 代码入口

| 职责 | 位置 |
|---|---|
| 许可接受后的展示、跨页保留 | `webui/src/App.tsx` |
| 四步教程与欢迎卡 | `webui/src/components/help/GettingStarted.tsx` |
| 页面导航、跳过与完成 | `webui/src/hooks/useOnboarding.ts` |
| 浏览器偏好的容错读写 | `webui/src/lib/onboarding.ts` |
| 手动重开入口 | `webui/src/components/help/HelpPage.tsx` |

## 关键决定

- 先邀请、用户主动开始；提示卡占正常页面空间，不覆盖按钮、不限制页面操作。每一步可以导航到实际页面，用户准备好后手动继续，允许直接跳到任意步骤。
- 只建议先连接常用的 1–2 个平台，不修改现有平台勾选偏好，不代替用户登录、搜索或同步收藏。
- 「搜索与查看」步骤在真实搜索页说明平台按钮：**它们是勾选框，不是状态灯**。带勾的平台参与本次搜索，没勾的本次不参与；没登录的平台可以先取消，避免本次搜不到。首次进入默认不预选任何平台，需要用户亲手勾选，一个都不勾时点搜索会提示先选平台（统一提示，不区分"首次"还是"已勾过又取消"）。结果页每个平台有独立状态块，失败的可以单独重试。再由用户输入关键词并按回车或点击箭头搜索。
- 「这次跳过」保留到当前标签页会话结束，刷新也不会反复提示；「以后不再自动提示」在关闭时写入当前浏览器。完成教程也停止自动提示。
- 帮助页总能重开，即使此前完成或永久关闭；重开不会清除原有永久偏好。进行中的步骤可在刷新后恢复。
- 许可接受前不展示；不与首次使用须知争抢注意力。文案同时提供中文和英文。
- 取舍见 `docs/decisions/2026-09-15-新手引导与诊断反馈.md`。

## 已知坑 / 边界

- 偏好按浏览器和访问地址保存。更换浏览器、端口或清理浏览器数据后会重新出现；首次升级到带引导的版本时，老用户也会看到邀请。
- 关闭浏览器后若浏览器恢复了原标签页会话，临时跳过也可能被保留。帮助页始终可手动重开。
- 完成教程只表示用户读完步骤，不作为真实登录、成功搜索或收藏完成的证据。
- 浏览器禁止写入偏好时仍可关闭本次引导，并提示无法记住长期选择。
- 本轮没有实测真实平台扫码；导航到账号页后的验证沿用该页已有行为。

## 测试怎么跑

- `webui/tests/onboarding.test.ts`：跳过范围、永久偏好、重开、刷新和存储容错。
- 前端编译、测试、lint 按根目录 `AGENTS.md`。
- 构建后运行 `scripts/getting_started_smoke.py`，用隔离浏览器和模拟接口验证许可前隐藏、完整教程、跳过、重开、快捷词保留平台选择以及窄屏布局。
