# AI 回答长图分享

## 一句话

AI 回答底部只保留复制、分享、重做三个图标。分享可以选择当前会话的一轮或多轮问答，预览后保存为本地 PNG 长图。

实际界面位于独立 SiYe-AI 仓库（以下路径相对本仓库根目录）的 `../SiYe-AI/webui/src/Panel.tsx`、`../SiYe-AI/webui/src/ShareImageDialog.tsx` 和 `../SiYe-AI/webui/src/shareImage.ts`。主程序提供翻译环境及扩展加载，必须同时使用本次构建的主程序界面和插件界面。

## 代码入口

| 职责 | 位置 |
|---|---|
| 扩展界面加载及宿主环境 | `webui/src/components/extensions/PluginUI.tsx` |
| 中文与英文文案 | `webui/src/i18n/locales/zh-CN/common.json`、`webui/src/i18n/locales/en-US/common.json` |
| 隔离浏览器验收、实际 PNG 下载检查 | `scripts/research_ui_smoke.py`（`check_answer_actions`、`check_share_image`） |

## 关键决定

- 三个回答操作使用图标，鼠标悬停和读屏仍有名称；复制保留来源链接，重做继续保留旧版本。回答工具栏不再提供写入笔记按钮。
- 点击分享默认选中当前回答，可逐轮勾选或全选；仅完成的回答可选，按原会话顺序输出。分享不会请求模型，也不上传问答。
- 预览可切换是否包含问题。长图保留正文排版、引用编号、每轮来源标题与链接，不含工具过程、输入框或操作按钮；始终使用白底，便于保存和转发。
- 使用浏览器原生绘图导出，不引入截图依赖。选择和预览是临时界面状态，返回选择保留勾选，退出分享后恢复原草稿。详见[本地长图导出取舍](../decisions/2026-10-27-AI回答本地长图分享.md)。

## 已知坑 / 边界

- 保存通过浏览器下载 PNG；不生成公开分享链接，不自动发送到聊天软件。用户需要自行转发下载的图片。
- 正常导出宽 1440 像素，过长时在完整保留内容的前提下减小倍率。超过浏览器画布保护上限时提示减少问答，不静默裁切或只保存屏幕可见部分。
- 只支持本应用现有文字回答结构，图片、视频、附件不进入长图。来源链接在 PNG 内是文字，需要根据原始会话访问。
- 浏览器实际下载与排版在 Windows Edge 验收；其它浏览器或极低内存设备仍可能生成失败，界面允许返回减少内容后重试。

## 测试怎么跑

- 构建主程序及独立插件前端，设置 `SIYE_AI_SOURCE` 为插件源码目录，运行 `.venv/Scripts/python.exe scripts/research_ui_smoke.py --share-only`。使用临时库和模拟模型，不读写真实用户数据。
- 覆盖三个纯图标操作、复制来源、重做保留版本、划词保留草稿、多轮选择及顺序、包含问题开关、长图实际下载与贯穿全图的非空白检查、超限提示、Esc 返回、390／320px 和白底输出；分享不增加模型任务。
- `npm run build` 检查两份界面的类型与构建；主程序 `npm run test:search` 及 `tests/test_docs_wiki.py`、`tests/test_webui_ui_contract.py` 检查现有前端和文档契约。
- 完整 UI 脚本仍有既有的侧栏宽度断言失败，新增分享独立验收通过不能代替完整布局验收。
