# 小红书图片文字 OCR

## 一句话

AI 研究自动读取小红书图文笔记配图里的文字，按原图顺序作为独立证据交给模型；不理解画面内容，不生成图片描述。

## 代码入口

| 职责 | 位置 |
|---|---|
| 图片下载、按图缓存、重试与隔离运行 | `api/services/research_ocr.py`（`OcrService.collect`、`download_image`、`recognize_image`、`run_ocr`） |
| Windows 本地文字识别和长图分块 | `scripts/research_ocr_worker.ps1`（`Await-Result`） |
| 原帖配图取得及 OCR 检查点 | `api/services/platform_materials.py`（`MaterialCollector.collect`） |
| 旧会话补取与公开状态 | `api/services/research_jobs.py`（`ResearchJobs.create`、`ResearchJobs.public`） |
| 冻结程序的图片解码入口 | `api/services/research_worker.py`（`run`）；`MediaCrawler.spec` |

## 关键决定

- 自动处理小红书图文原帖的配图，沿用现有账号取得详情和图片顺序；不对视频封面、评论头像或其它平台图片做 OCR。配图地址只用于采集进程，不传给模型。
- 使用 Windows 内置中文 OCR，离线识别、不需要图片理解模型或 OCR Key；常见 JPEG、WebP、PNG 由项目已有 Pillow 在隔离子进程解码，透明底按白底合成，遵从 EXIF 方向。没有新增依赖。取舍见[本地图片文字识别](../decisions/2026-10-27-小红书本地图片文字识别.md)。
- 长图按高度分块，边缘重叠并按文字与位置去重，避免直接缩小整张长图造成小字丢失。保留行次序和原图编号，不能据此恢复表格结构、版面语义或被遮住的内容。
- 图片文字在独立 SiYe-AI 扩展中是单独的必读分区，与正文、评论一起完成补读检查；普通回复、结构化结果、流式引用和 30 分钟上下文复用使用相同来源校验。图片里的命令仍只是来源文字。
- 处理进度、成功／失败、图片序号及缓存命中在资料详情显示，获取成功与 AI 实际读取分别统计。每张图完成后保存检查点；取消和超时保留已取得文字。
- 已成功的每张图单独缓存 30 天；无文字的成功识别也缓存，失败不缓存。重试保留成功项、只补失败图片；旧会话第一次追问会补取过去没有采集的配图文字。完成回答后的「重试图片文字」在新轮次补取并重答，保留原回答。

## 已知坑 / 边界

- 需要 Windows 10/11，并装有中文 OCR 语言组件；没有组件时显示中文安装提示，不自动安装。其它系统显示不可用，已有正文、评论和字幕仍保留。
- 原图受登录、CDN 或链接时效限制时可能无法下载。无可取图片、未识别出文字、图片失败分别显示；不能把无字识别结果当成“图片没有信息”。
- 每帖最多识别前 60 张、累计处理最多 90 秒；每图下载最多 8 MB、单图最多 4000 万像素，校正方向后宽度最多 10000、高度最多 40000；单图文字最多 24000 字、OCR 分区沿用 256000 字保留上限。超限或超时明确显示缺口，仍受整轮十分钟任务限制。
- OCR 会有错字、漏字、数字间断和阅读顺序错误；手写、小字、复杂表格、竖排、旋转与低清图片尤其需要对照原图。读取记录证明文本交给模型，不保证 OCR 或回答正确。
- 持久缓存仅保存识别文字和语言，不保存图片、带签名链接、Cookie 或模型密钥；最多 512 项／32 MB。临时图片随任务清理。旧的主程序或插件不能提供完整 OCR 链路，必须一起更新；不自动覆盖已安装版本。

## 测试怎么跑

- `.venv/Scripts/python.exe -m pytest tests/test_research_ocr.py tests/test_research.py --basetemp=.tmp_pytest_ocr/<新目录>`：覆盖多图顺序、空图、失败保留与重试、下载限制、公开 DNS 校验、缓存过期、取消、旧会话补取；Windows 上包含真实中文长图、分块交界、JPEG／WebP／透明 PNG 识别。
- 独立 SiYe-AI 的 `test_image_ocr.py` 检查两种模型协议的必读、分段图序、引用与上下文复用，旧历史没有 OCR 分区时仍可读取。
- 构建两份前端、设置 `SIYE_AI_SOURCE` 后，运行 `scripts/research_ui_smoke.py --ocr-only`；使用临时数据验证获取／已读进度、失败图片编号、引用链接、保留旧回答的重试与窄屏布局，不访问真实模型或平台。
- 候选 EXE 通过原研究 worker 的 OCR 模式验收本机生成的中文图片；构建资产应包含脚本资源，不能只以源码测试代替冻结运行检查。
