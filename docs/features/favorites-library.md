# 本地收藏夹

## 一句话

用户收藏保存在稳定的本机 SQLite 中；「已收藏」「放在哪些收藏夹」「稍后再看」是三个各自独立的状态，一条内容可以同时属于多个收藏夹。

## 关键决定

- 内容列表与网格沿用[搜索体验的共同视觉约定](search-experience.md)：紧凑封面也保留占位与地址回退，平台身份、指标单位和操作样式一致。切换回列表保留展开状态；收藏时间、归属编辑与备注统一通过详情查看。

- 视频有可靠时长时，在封面右下角显示分秒或时分秒；接入 B 站、抖音、小红书视频及知乎独立视频在已有响应中提供的时长，不为此追加请求。小红书已识别为视频的内容可读取视频流中以毫秒计的时长；缺失时不显示、不推算，也不回填旧收藏。图文配乐和回答、文章内嵌视频的时长不作为整条内容时长。时长随历史、收藏和备份快照保留，旧数据兼容。

- 详情抽屉中收藏成功后也自动弹出居中归属卡片；关闭卡片返回收藏按钮，抽屉保持打开。取消收藏、收藏失败与稍后再看不触发此弹窗。

- 封面底部使用带阴影的白色类型和指标，不铺整条黑色渐变。网格封面左下角、内容类型标签右侧，以列表同款图标加紧凑数字（k / M / B，如 15.4k、1.2M）展示一个已有主要指标，近似值用 ≈ 标识，悬停和无障碍名称保留完整含义：优先播放／阅读，其次点赞及其他已有互动数据，保留近似值标记；缺失不补零，真实零正常显示。聚合卡不叠加各来源数值，完整数据仍在详情查看。

- 两种视图中收藏成功后直接弹出居中的收藏夹归属卡片，可勾选归属并完成、按 Esc 或点击外部关闭。关闭不会撤销收藏；卡片下不插入收藏时间、备注或编辑入口，网格布局保持不变。收藏时间、归属与备注统一在详情内查看和编辑，列表不再显示重复的编辑横条。

- 内容视图开关使用简短的「列表 / 网格」。网格卡片的平台名称配主题色圆点，桌面上与原文及适用操作排在同一行；手机窄屏将操作统一排在平台下方。封面和标题继续打开详情，触屏保留较大的点击区域。

- **一条内容可属于多个收藏夹，底层只存一份**：`UNIQUE(platform, content_id)` + 关联表。
- 固定内置视图按「全部 → 默认收藏夹 → 稍后再看」排列，再显示自建收藏夹。**没有「未分类」视图**（2026-09-23 按用户要求移除，见[决策记录](../decisions/2026-09-23-移除未分类视图.md)）：图标网格不提供入口。后端 `stats.unclassified` 与 `GET /items?unclassified=true` 保留为数据能力，只是界面上没有入口
- **本地收藏固定图标导航**：根页浏览内置分类与自建夹，进入后可切换内容列表与封面网格，不恢复左侧收藏夹列表；内容偏好独立保存在本机，旧文件夹浏览方式偏好不影响导航。返回恢复根页滚动位置与卡片焦点，刷新回到图标根页。
- 夹内「返回收藏夹」使用紧凑左箭头与主题色文字，不显示矩形底色或边框；悬停显示下划线，键盘聚焦保留可见提示，深浅主题及跨平台夹内入口保持一致。
- **图标内容卡打开详情抽屉**：卡片显示封面、类型、两行标题和平台；完整标题、已保存简介、互动数据、收藏时间、备注与归属在抽屉查看和操作。无封面或加载失败显示占位，不补抓平台数据，也不把缺失指标显示成零。「在原平台打开」是独立入口，查看抽屉不记作观看历史。取舍见[封面网格与详情抽屉](../decisions/2026-09-27-本地收藏图标内容网格.md)。
- 抽屉支持关闭按钮、点击外部空白及 Escape；焦点留在抽屉内，关闭后返回原卡片。归属菜单或取消收藏确认打开时，Escape 先关闭内层。未保存备注关闭前提醒，保存失败保留草稿；仅移出当前夹时可继续看详情，彻底删除内容后关闭。窄屏抽屉占满宽度，保留显式关闭入口。
- 抽屉内「编辑归属」在屏幕中央弹出，长收藏夹名可换行；完成、Escape 或点击外部关闭后回到编辑入口，详情抽屉保持打开。
- 抽屉直接显示「所在收藏夹」：全部收藏、已加入的默认收藏夹和自建夹；编辑归属成功后同步更新，长名称换行。「稍后再看」仍在独立状态按钮中显示，不混入收藏夹归属。
- 图标内容的小红书封面先加载保存地址；已识别的带时间戳 CDN 地址失效时，仅尝试一次对应原图地址，不改写收藏快照。知乎无封面或图片失败时，用已有标题、摘要生成主题卡，不抓取或伪装成原站页面截图。
- 内容页标题旁保留自建夹「编辑信息 / 删除」；新建入口仅在收藏夹根页打开信息卡片。根页「整理顺序」提供前移、后移按钮，触屏与键盘均可操作。批量管理、平台/关键词筛选、导出与「显示更多」继续复用原有能力。
- 根页自建夹卡片只负责浏览。新建和编辑复用同一张信息卡片，可填写名称、简介并选择封面；封面可留空。进入夹后可编辑名称、简介和上传封面，夹内不显示新建入口；删除收藏夹后返回根页，夹内内容保留。

- 图标模式的自建夹封面优先使用用户上传的图片；未设置时按关联记录的「加入该夹时间」挑最近且已有缩略图的内容。内置分类没有单独关联时间时按本机收藏时间降级，绝不借用内容发布时间。卡片摘要直接从已载入本地数据计算，不请求平台或逐夹补详情；空夹、无图和图片失败统一显示占位。
- 自定义封面经图片校验、缩放后存入本机收藏库，导出备份时包含简介和封面，导入旧版备份仍受支持；旧库合并也保留新格式中的简介与封面。封面文件限 5 MB，备份导入限 64 MB；可在编辑卡片恢复自动封面。详情页显示封面、名称及简介。存储取舍见[决策记录](../decisions/2026-09-26-自建收藏夹封面保存.md)。
- **「已收藏」是独立状态**（`saved`）：「全部」只显示已收藏的内容，且不可编辑——收藏了就一定在，没收藏就一定不在（也不会在任何其他收藏夹里）。只挂在稍后再看上的内容不进「全部」。
- **取消收藏 = 从本机彻底移除**（和「从本机彻底删除」是同一个动作，走同一个接口）：整条记录连备注、所有收藏夹归属一起删掉，所以它必然从「全部」消失。点之前弹一次居中确认框（456px 宽），标题「是否要取消收藏」；破坏性按钮做实底红色、默认焦点落在「取消」上（避免回车直接删），并提供「下次不再提示」（存 localStorage，勾过就不再问）。
- **稍后再看完全独立**：只由卡片上的稍后再看按钮控制，不进归属面板，也不影响收藏状态。详见[收藏状态与稍后再看分离决策](../decisions/2026-09-21-收藏状态与稍后再看分离.md)。
- 内容卡常驻原文、收藏与稍后再看入口，不依赖悬停；后两者各自独立。搜索聚合卡仍可按平台版本选择，窄屏来源菜单显示在屏幕底部。
- 已收藏条目的「编辑归属」列出「全部」、默认收藏夹和自建收藏夹；「全部」保持勾选且不可编辑，其他归属可独立勾选。**面板里没有稍后再看**——它由独立按钮负责。
- 两种视图的收藏时间、归属和备注统一放在详情抽屉，列表下方不再常驻重复的编辑横条。取消收藏继续走原有确认。
- **收藏成功后当场给一次「编辑归属」**：列表与网格均直接打开居中归属面板，不用去收藏页找条目。只在"加入"成功时触发，关闭后收起；聚合卡片按整批来源生效（勾选框半选表示部分命中）。详见[收藏后即时编辑归属决策](../decisions/2026-09-21-收藏后即时编辑归属.md)。

- **删除收藏夹默认保留内容**，只解除归属。
- 批量管理支持加入或移出两个内置收藏夹、加入或移出自建收藏夹；「从本机彻底删除」与单条的「取消收藏」是同一个动作（同接口），都会让条目从「全部」消失并要求确认。
- 「移出默认收藏夹」（归属面板里取消勾选默认收藏夹、批量管理里的移出）**不是**取消收藏：只解除归属，内容仍在「全部」里。
- 自建收藏夹不能新建或改名为系统名称。历史同名收藏夹原样保留，界面追加「（自建）」帮助区分。
- 重复收藏只刷新内容快照，**保留首次收藏时间与已有备注**；改备注只能走 `PATCH`。
- **互动指标只合并、不倒退**：重复保存时本次没带的字段沿用库里已有的值（搜索结果先出现、详情指标后补，补全前收藏一次不会把以后补上的值清掉）。
- 沿用既有前端限制：备注 1000 字、总量 500 条。
- 内容列表和网格每批只渲染 100 条，底部「显示更多」继续展开；筛选、导出和批量操作仍覆盖完整结果，不会因为分批显示漏数据。
- 旧 `localStorage` 收藏**只提示、不自动删**；迁移有跳过项时**不写**完成标记（否则用户失去迁移入口）。
- 新版本首次启动会检查源码根、当前程序目录及旧 `dist/MediaCrawler`、`dist/SiYe` 的数据库。合并按平台与内容 ID 去重，保留非空备注和全部归属；迁移前备份目标库，旧库不删除。源库内容改变后可再次幂等合并。
- 迁移成功在收藏页显示一次恢复摘要；坏库会显示警告，不能读取的源不会清空现有目标库。
- 这次只移动 `library.db`；登录 profile、日志和其他缓存仍使用原位置。详见[稳定收藏库目录决策](../decisions/2026-09-16-收藏内置分类与稳定数据目录.md)。
- 并发重复收藏用 `INSERT OR IGNORE` + 冲突退化为更新（幂等），避免撞 UNIQUE 直接 500。
- 多个页面共享收藏状态；备注以实际写入成功为准，失败时保留草稿，方便直接重试。
- 导入结构出错时回滚整次操作；条目无效或超出容量则按实际跳过数量反馈，避免误报全部成功。

- 搜索、观看历史与跨平台归档共享列表 / 网格切换及详情抽屉；详情从页面快照读取，不要求先收藏。各页面的操作权限保持原样，历史页不新增收藏与备注入口。取舍见[统一内容网格](../decisions/2026-09-27-统一内容网格.md)。

## 已知坑 / 边界

- **`.row-actions button` 不能用后代选择器写**：操作入口的尺寸规则会连下拉面板里的
  文字按钮一起命中，把「全部加入收藏」压成一个方块（文字竖排）。现在收窄成
  `.row-actions > button, .row-actions > .relative > button`。
- `PATCH /items/{platform}/{content_id}` 把 content_id 放**路径参数**：含 `/` 的 ID 会被切段，
  可能改错条目或 404。当前数据无此情况，其他接口都走 body。
- 500 条上限在批量导入时按实际条目数判定，超限条目被跳过并反馈。
- 本地库**缺并发/锁测试**；长导入是单条 `BEGIN IMMEDIATE` 事务，并发写超过 10s 会超时。
- 传了已删除的 collection_id 会让该条内容**整条**收藏失败（单条 400，批量静默跳过）。
- 备注超 1000 字是**静默截断**，不给用户提示。
- `LOCALAPPDATA` 不可用时才回退到应用目录；目标目录不可写会让启动明确失败，不会静默改读空库。
- 图标根页不提供按夹名搜索；进入夹后可筛选内容。内容类型与元数据按已有快照显示，未知类型标记「内容」，竖图与视频封面用统一格子完整容纳；卡片长标题截成两行，抽屉展示完整标题。
- 小红书 CDN 仍受网络、下架与源站策略影响；回退只覆盖已识别路径，原图也失败时显示「封面暂不可用」，不请求登录态、不代理图片。没有保存封面地址时无法凭内容 ID 自动恢复图片。
- 收藏夹信息菜单锚定内容页标题旁，窄屏不越界；菜单和编辑卡片支持键盘焦点、Escape 关闭及点击外部关闭。
- **卡片的视觉几何与跨平台那份共用**（一页 16:9 海报 + 后面两层副本：每退一层左右内缩 8px、上移 5px，只从顶部露出；数量是海报右下角的白色角标，不再放在下面那行；封面格只放封面图与角标，不再渲染占位图标）。详见[跨平台收藏同步](remote-favorites-sync.md)；只改一份会让两边漂开，`tests/test_webui_ui_contract.py` 有守卫。
- **CSS 变量拼错不会报任何错**：`border: 1px solid var(--siye-border)` 这种简写会整条降级成 `border-style: none`（元素一个像素都不画），`background: ... var(--siye-surface) ...` 直接失效。2026-09-22 就是这五个幽灵变量（`--siye-surface` / `--siye-border` / `--siye-primary` / `--siye-text` / `--siye-danger`）让「两层副本」完全没渲染、空收藏夹变成一块纯白板。正确名字是 `--siye-bg` / `--siye-line` / `--siye-brand` / `--siye-ink` / `--siye-red`，`tests/test_webui_ui_contract.py::test_css_theme_variables_are_all_defined` 专门拦这一类。
