# 安装器语言文件

`ChineseSimplified.isl` 来自
[`kira-96/Inno-Setup-Chinese-Simplified-Translation`](https://github.com/kira-96/Inno-Setup-Chinese-Simplified-Translation)，
固定于提交 `1ff90acc4ed4aee82b1cda43253243deee3daed4`，适配 Inno Setup 6.5.0 及以上版本。

该翻译以 MIT License 发布，许可证全文保存在同目录的 `LICENSE`。语言文件随仓库保存，
是为了让本机和 CI 构建不依赖编译器安装目录中是否额外带有简体中文翻译。
